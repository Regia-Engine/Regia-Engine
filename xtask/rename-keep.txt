# What `cargo xtask rename-brand` must NOT change (ADR-1388, docs/rename-regia.md).
#
# The list is compiled into the tool (`include_str!`), so every branch converted by the same xtask
# binary gets the same result. One rule per line:
#
#   keep-file <glob>      neither the path nor the content changes
#   keep-content <glob>   the content is kept; the path still moves with its crate directory
#   keep-text <literal>   the literal is protected wherever it appears
#
# Globs are matched against the old and the new path (relative, `/`-separated); `**` crosses
# directories, `*` and `?` do not. In-file markers protect too: a line containing `rename-keep`,
# and every line from `rename-keep-begin` to `rename-keep-end`.
