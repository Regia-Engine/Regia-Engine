# Ferrite v0.1.6

Patch release for Direct Order 27's alpha (Saturday 2026-10-17): fixes for the lag, the quit freeze and the muffled
audio found in the owner's first plays, plus the first Windows run on a real GPU.

- **Commit:** v0.1.6 = the tag `v0.1.6` (the gated code commit is named in the tag message).
- **Workspace version:** `0.1.6`.

## Upgrade from v0.1.5
No host source changes: every API below is new. One behavior change needs a look:

- **Texture cameras render a reduced feature set, also without `TextureViewSettings`.** Every camera with
  `RenderTarget::Texture` (cockpit screens, feeds, maps, mirrors, UI previews) now renders without temporal AA,
  SSAO, SSR, SSGI, contact shadows, fog, clouds and probe lighting, with two sun cascades. Before, such a camera
  rendered at window quality through the window's own state, which cost DO27 60–87 ms of GPU per frame. Check each
  texture camera by eye after updating; tune it with `TextureViewSettings` (checklist § Texture views (v0.1.6)).

## Fixed
### Texture views wrecked the window's frame (ADR-184)
Each texture view keeps its own targets, history, shadow maps and terrain state, so the window's frame is the same
with the views on as off (bit-identical in the tests) and steady frames create no GPU objects. New: per-view
`update_every` / `paused`, GPU binding of a view's image into a material (`TextureViewSettings::with_texture`) or a
UI image (`UiRenderer::add_image_view`), a non-blocking `request_texture_readback`, and `frame_summary.texture_views`.
`read_texture_target` is blocking: tools and tests only.

### Resizes kept their render targets (VRAM leak)
Every window size, fullscreen toggle and dynamic-resolution step left its render targets allocated, held by cached
bind groups and a per-size target map (DO27 on an RX 7900: 2.7 → 17.5 GB in 20 s, kept after the churn stopped).
Replaced targets are now released at once and idle sizes within 4 frames. Lavapipe test (Desktop High, 20
large/small toggles plus a 16-size drag): 297 → 1788 MB before, 297 → 297 MB after; RTX 5080: 307 → 311 MB. This was
also the owner's long freeze on quit (the kernel freeing tens of GB of VRAM at exit).

### Audio dropped out, then stayed muffled (ADR-185)
After the audio device was suspended (a dropout, a device change), voices that were playing never reported stopped:
the voice and boom ducks (−6 / −4 dB) stuck for the rest of the session and each cycle leaked a voice slot. A host
resume in Update plus the engine's own resume rebuilt the buses twice, killing restarted loops and resetting bus
volumes. Now `suspend_output` ends every voice, `resume_output` is a no-op on a live output and re-applies the host's
bus volumes and mutes after a rebuild, and the output gate resumes only if no one else did. Patch-layer
`filter_curves` now actually filter (the loops play through their low-pass track): engine and hover hum are low-passed
as authored. New: `Audio::output_suspended()`, `Audio::start_asset` (returns a stoppable voice id; `play_asset` is
unchanged). Not restored across a suspend (unchanged): music stems and spawned patches; re-spawn them after a resume.
Offline-backend tests: 6/6 failed on v0.1.5, 8/8 pass.

## Tools
- `cargo xtask alpha-triage <dirs-or-files> [--out report.md] [--json]`: turns alpha session logs (and feedback
  bundles) into a triage report: per-session GPU, settings and frame times, top hitch causes, crash signatures, and a
  "suspected engine issues" list.

## Windows
First run on a real GPU (Windows 11 VM, GTX 1080 by VFIO, NVIDIA 582.78, Vulkan), on v0.1.5:
`boot_probe --exit --game` 3/3 (shader warm 13.7 s cold, 3.0 s warm; no pipeline compiled after the warm), the arena
sample 1800 frames, engine tests 463/0. Known gaps: quitting during a first-launch warm can take 2–3 s on a slow CPU
(no Windows exit hook yet); the shipped pipeline cache adds little on Windows NVIDIA (the driver keeps its own); DX12
is untested (Vulkan is the default and the tested path); native crash capture is Linux-only.

## Known issues
- Texture views use ambient light, not the window's GI probes, and redraw their 1–2 sun cascades on each refresh
  (set `sun_cascades` 1 or 0 for a map view).
- A view that is hidden or paused keeps its targets until it has been gone 120 frames.
- Everything listed under v0.1.5 still applies, except the items fixed above.
