# Ferrite v0.1.3

Patch release for Direct Order 27's alpha (Saturday 2026-10-17). One fix.

- **Commit:** v0.1.3 = the tag `v0.1.3` (the gated code commit is named in the tag message).
- **Workspace version:** `0.1.3`.
- **Upgrade from v0.1.2:** no host code changes. Hosts that set `paged_sun_shadows = false` as a workaround for the stale shadow
  patches can turn paged shadows back on (it saves GPU time on static scenes).

## Fixed

### Black, blocky stale shadow patches on vehicles (paged sun shadows)
- **Symptom (DO27, Foundry / Reclaimer crewfit captures, desktop High):** jagged pure-black patches on flat hull decks, offset copies of
  raised plates and blobs where a dome used to be, with straight edges on shadow-page boundaries. Shown most with a held camera.
- **Cause:** the paged sun-shadow cache (`SunPageCache`) and the local-light atlas cache (`AtlasTileCache`) decided whether a caster had
  moved from a cube around its bounding sphere, compared with the previous frame. A caster that **turned in place** kept the same cube,
  and a caster that **crept** less than the tolerance per frame was never detected, so its shadow pages (and the near sun tile) were never
  redrawn.
- **Fix:** each caster records its model matrix and bounding sphere; a cached page is reused only while every point of that sphere has
  moved less than the tolerance since the page was **drawn** (rotation, scale and motion along the light count; creep accumulates).
  Static scenes are unchanged (pixel-identical held frames on an RTX 5090).
- **Tests:** `frame::tests::a_caster_turned_in_place_redraws_its_shadow_pages` (fails on v0.1.2) and three CPU tests in
  `paged_shadow::tests` (turn in place, creep, atlas turn).

## Known issues
- A caster whose transform jitters by tiny amounts every frame (physics at rest, non-bit-exact network interpolation) now redraws its
  pages once the jitter passes the tolerance: correct pixels, possibly more page redraws. The local-light atlas tolerance is a fixed
  1e-4 m; if profiling shows churn on large parked hulls, it should scale per tile (follow-up).
- A local light that moves less than 1e-4 m per frame still never redraws its atlas tile (pre-existing; follow-up).
- Everything listed under v0.1.2 still applies.
