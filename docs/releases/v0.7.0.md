# Regia Engine v0.7.0

Builds on v0.6.0. The v0.6.1 line was never tagged, so this note also carries its work: the MPL-2.0 licence switch,
the public-export/readme work, the v0.6.1 fixes, and every v0.7 fragment first landed after v0.6.0. v0.7 is the game
release: a team can build and ship a networked game on Regia, and the DO27 switch package names what must move, migrate,
re-cook and verify before the switch.

Read **Upgrade: host changes since v0.6.0** first if you build a game or a shell against the engine crates. New
features are off, or leave existing projects unchanged, unless **Changed** says otherwise.

## What v0.7 delivers

- **Shipping netcode.** Wire 6, transport/session resume, far-tier transform records, a larger replication version ring,
  peer-quality reporting, capture/replay, replay audit and external-replication stats, lobby-hub packaging, and the
  v0.7 net-soak gate row.
- **Gameplay rules that can ship.** Frozen `.rules.ron`, `.playlist.ron` and `match-result` formats; match results;
  ruleset/playlist hashing; capture zones; BR/RTS/PvE/racing rules; and the rules editor/guide/sample.
- **Tunnels and low-tier runtime readiness.** Faster native tunnel queries, nav-cell v3, TerrainMap cell-centered
  spacing, terrain-index v3, cooked mesh-layers v2, volume-sourced mesh layers, indoor portal/shadow culling, masked
  occlusion on Desktop Low and Deck, an integrated-low memory row, and the showcase tunnels scene.
- **Animation and determinism follow-through.** Gait v1 freeze, locomotion editor/guide work, gait/foot-placement
  follow-ups, deterministic nav in its own crate, det small follow-ups, and the lockstep/gameplay/world known-issue
  fixes that landed.
- **Release and switch tooling.** MPL-2.0/SPDX/public-export, containerized Linux packaging, hosting-CLI release
  uploads, fast exit and single-instance guards, the v0.7 upgrade guide, and the DO27 switch package page.

## Added

- **Networking**
  - Wire 6 (`REGIA_NET_WIRE_VERSION = 6`) with resume tickets, resume credentials, arrival stamps, far-tier transform
    records, a 512-entry replication version ring, connection-quality reporting, replay audit, capture/replay tools and
    `net.rejections`.
  - `regia-lobby-hub` ships with server packages, and the hub/session/ticket path gained the store-ticket hook on every
    server type, join-code revocation, the dedicated `--no-port-map` switch, and persistent lobby identities.
- **Gameplay and rules**
  - Frozen rules formats for v0.7: `.rules.ron` v1, `.playlist.ron` v2, `match-result` v1 and `.gait.ron` v1.
  - Match results, ruleset/playlist hash plumbing, `MatchSession::version`, option `bind` rows, `return_zones`, and
    the `WinCondition` reporting adapter.
- **World, terrain and rendering**
  - Showcase tunnels, native-query speedups, nav-cell v3, cell-centered terrain samples, terrain-index v3, GPU mesh v3,
    decal v3, mesh-layer LOD cross-fade, volume-sourced mesh layers, interior portal/shadow culling, and masked CPU
    occlusion for Desktop Low / Very Low / Deck.
  - Named low-tier/profile work: `ProfileName`, `BudgetTier::IntegratedLow`, per-tier integrated-low reporting, and
    `VeryLow` by name in config, tooling and agent methods.
- **Animation and determinism**
  - The locomotion editor/guide line, gait posture simulation overrides for agents, graph-output foot tilt/toe bend,
    `EcsDesyncHash::order_by_content`, `DetInputHost`, and tick-targeted `sim.host_snapshot`.
- **Release/docs**
  - MPL-2.0 licensing/public-export work, the v0.7 upgrade guide, and the DO27 v0.7 switch-package page.
- **Privacy: executable host-string gate (carried from the v0.6.2 patch, ADR-10354)**
  - `regia package` scans every staged executable (ELF, PE, Mach-O, WebAssembly) for private build-machine strings
    (farm host names, the `/home/`, `/media/`, `/srv/`, `/models/` roots, LAN addresses, tailnet names) and refuses
    the package on a hit (rule `host_string`, byte offset only). Reviewed false positives go in a TOML allow file
    named by the new optional `[package] host_strings_allow` key; the standalone check is
    `regia_cli::package_hygiene::check_executable_strings`.
  - `cargo xtask host-strings [--binary PATH]... [--allow FILE]` runs the same gate on any built executable.
- **Editor agent surface**
  - `editor.anim_gait_load` / `editor.anim_gait_save` drive the Gait authoring inspector's `.gait.ron` Load and Save
    (ADR-10358).

## Changed

- **Open-source release line.** The engine is now under MPL-2.0; templates and samples are MIT-0 / CC0-1.0, docs and
  the book are CC-BY-4.0, and `regia package` writes the engine notice/license files and default engine credit.
- **Packaging and exits.** Linux packages can build inside pinned glibc-floor containers; server packages stage
  `regia-lobby-hub`; `quit.request` can ask for a fast exit; a second app instance is refused per user/app.
- **Low-tier defaults.** Very Low streams at most 384 MiB with lazy first use on every machine; masked occlusion is on
  for Desktop Low / Very Low and Deck; the integrated-low row is available in agent/report surfaces.
- **Game/runtime behavior**
  - A remote player's rules-spawned character now despawns when the player leaves unless the game keeps it.
  - Deterministic grid search scales its own heuristic on cheap areas.
  - Peer-quality, rate-control and staleness reporting surfaces gained the new queueing/path breakdowns used by the
    v0.7 soak work.
- **Release tools are editor-host agent methods (ADR-10356).** `release.verify`, `release.diff`,
  `release.sign_status` and `release.upload_dry_run` moved from the runtime dispatcher (`regia_agent`) to the editor's
  agent extension (`regia_editor::agent_ext::install`), next to `asset.export_glb`; names, parameters, results,
  permission and error codes are unchanged. Runtime crates no longer link the pipeline layer (`cargo xtask
  check-layers`: 0 problems), and the `release-signature` fuzz and corpus checks run in `regia_release_chunks`.
- **Build-machine paths are remapped out of every artifact (ADR-10354).** The workspace `.cargo/config.toml` remaps
  the generic directory roots to `/builder` for the Linux, Windows and wasm32 targets, and `regia package`'s shipping
  home remap lands on `/builder` (was `/home`). `hello_window` resolves its agent project directory at run time.
- **Mesh-layer caches re-cook once** after an upgrade: the cook key includes the skylight revision (ADR-10346).
- **DO27 switch docs.** The switch package now points at the v0.7 upgrade guide, format-batch-2 recooks and the tests
  that prove each replacement.

## Upgrade: host changes since v0.6.0

- **Licence and packaging**
  - The engine now ships as MPL-2.0. `regia package` writes `REGIA-ENGINE-NOTICE.txt`,
    `REGIA-ENGINE-LICENSE.txt` and `CREDITS.txt`; use `--no-engine-credit` to drop the default credit line.
- **Wire 6 is the v0.7 network floor**
  - Update clients and servers together. A wire-5 peer is refused with `protocol_mismatch`.
  - The transform-record revision also moved (`far` record support), so mixed v0.6/v0.7 runtime pairs are not
    supported.
- **Removed deprecated networking names**
  - `Channel::Reliable` is removed. Use `Channel::GAME_RPC` (or `Channel::Stream(StreamId::GAME_RPC)`).
  - `congestion::CongestionNotches` is removed. Rename it to `congestion::LossNotches`.
- **Run the source/data upgrade**
  - Run `regia upgrade-project --write`, then `regia cook` (`docs/guide/upgrade-v07.md`).
  - Source-format steps on the v0.7 line include scene 14, `.logic.ron` 2, `.uianim.ron` 2, `.playlist.ron` 2 and
    `.decal.ron` 3.
  - Cooked/runtime content that must be re-cooked on the v0.7 line includes nav-cell v3, terrain-index v3, terrain
    mesh-layers cooked v2, TerrainMap spacing changes where a level opts into `CellCentered`, and desktop paks that now
    use GPU mesh v3.
- **High-risk compile breaks**
  - Expect new struct fields and enum variants across the v0.7 net/render/terrain/rules/profile surfaces, especially in
    `handshake::Accept`, `ClientConfig`, `EndpointTotals`, `AckFrame`, replication/state counters, `RenderProfile`,
    `TerrainIndex`, `LevelTerrain`, `MatchSession`, `RotationView`, `PackageArgs`, and the connection/quality/status
    reports.
- **Release agent methods left the runtime protocol (ADR-10356)**
  - `release.verify`, `release.diff`, `release.sign_status` and `release.upload_dry_run` are no longer runtime agent
    methods: a game or tool that embeds `regia_agent`'s `AgentPlugin` without the editor answers method-not-found.
    Call them on a host that installs `regia_editor::agent_ext::install` (the editor and its headless agent host).
  - Their contracts moved from `regia_agent::contract::EXTENSION_CONTRACTS` to `RELEASE_HOST_CONTRACTS`; look them up
    with `regia_agent::contract::contract(method)`.
  - The fuzz target `release.signature` left `regia_agent::fuzz_targets::targets()`; the format is fuzzed by
    `crates/regia_release_chunks/tests/fuzz.rs`.
- **Path remaps and the host-string gate (ADR-10354)**
  - The workspace rustflags change rebuilds every dependency once; panic locations read `/builder/...` (map them in a
    debugger with `set substitute-path /builder <real root>`).
  - A project that sets `RUSTFLAGS` replaces the config-file remaps: restate them, most specific prefix last, or the
    host-string gate refuses the package. Additive API: `check_executable_strings`, `[package] host_strings_allow`,
    rule `host_string`.
- **Rules/content handshake**
  - `.playlist.ron` v2, scene v14, decal v3, v0.7 paks and wire-6 peers are refused by older runtimes. Deploy the
    runtime, content and clients together.

### Owner-ruled exceptions for v0.7.0

### Other open v0.7-line issues

- `KI-RN-001`: scatter impostors and water still see only the sun (`v07-interior-cull-portals`).

  automatically (ADR-10354).
- The editor stays desktop-only at run time; the Android file-dialog and SpaceMouse stand-ins only let the workspace
  check compile every member (ADR-10356).
