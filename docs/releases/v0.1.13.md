# Ferrite v0.1.13

Patch release for Direct Order 27's alpha build, made on `release/0.1` from v0.1.12. It fixes a normal, visible, focused window being
flapped into the hidden throttle (DO27 session 2026-10-16, Hyprland, Radeon 7900, Wayland): lobby frames went 54 -> 25 -> 10 fps with
`no redraw for 250ms; throttling until the window is visible` and `audio output paused: every window is hidden`.

- **Commit:** v0.1.13 = the tag `v0.1.13` (the gated code commit is named in the tag message).
- **Workspace version:** `0.1.13`.
- **Branch:** `release/0.1` (alpha hotfixes). `main` is the post-alpha development line (batch v020); this release is merged forward into it.

## Upgrade from v0.1.12
No host source change. One new environment variable: `FERRITE_NO_HIDDEN_THROTTLE=1` (see below).

## The redraw-stall heuristic no longer reads a slow frame as a hidden window (ADR-215)
Cause: the stall detector stamped `last_redraw` when a redraw *started* and flagged a stall when `last_redraw.elapsed() > 250 ms`.
Any single frame that took 250 ms or more (a scene load, the game-frame warm, a driver hitch) made the very next wake-up read "no
redraw for 250 ms" although the compositor had withheld nothing. The loop then ran throttled frames without presenting and paused
audio, which lowered the frame rate and produced more long frames. DO27's log shows the first throttle line inside the warm's 467.9 ms
frame, and `focused: true, occluded: false, stalled: true` 40 s later.

Now:
- The stall clock starts when a redraw is **requested** and not yet delivered, not when the last frame began. Time inside our own frames is never a stall.
- A **focused** window needs the request to stay undelivered for **2 s** (an unfocused one keeps 250 ms, the hidden-workspace case).
- Explicit occlusion and minimise signals are unchanged. The v0.1.10 present-anyway override (focused or fullscreen, hidden for 2 s) is unchanged.
- `FERRITE_NO_HIDDEN_THROTTLE=1` turns the stall heuristic off entirely (only explicit occlusion and minimise hide the window). Not needed for
  normal play with this fix; it is an escape hatch. Without the heuristic a window on a hidden Wayland workspace keeps presenting and can block in present.

Tests: a slow frame is not a stall; an undelivered redraw stalls an unfocused window after 250 ms; a focused window needs 2 s; the switch disables it.
