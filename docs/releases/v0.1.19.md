# Ferrite v0.1.19

The first main-line tag since v0.1.15. It carries the v0.1.16 to v0.1.18 patch line (out-of-memory
survival, cheap own-canopy glass, emissive combat-hitch fix) forward, plus everything that was
gated on main in the post-alpha batches. The v0.2.0 version number is reserved for baked light
(owner, 2026-10-18); nothing here is called v0.2.0.

## For DO27

- **Terrain holes** (DO27 ask 4, ADR-247): a versioned `<map>.holes.ron`, hole-aware picking, DDGI
  probes, path tracing and the GI bake; a 30 m tunnel-mouth fly-through test at every LOD.
- **Render-world lifecycle and skinned bounds** (ADR-248): draw-window entries are released when
  their meshes go; skinned meshes cull by a bound from the joint palette.
- **Audio zones** (ADR-250), **`ferrite_pick`, `MapLayer` and `world_pick`** (ADR-251), **the radial
  wheel** (ADR-254), **Steam core** (ADR-253), **preflight and schedule-shuffle checks**
  (ADR-255), **dynamic resolution** that keys on GPU time (ADR-256), **exposure zones as data and
  math** (ADR-257), **glTF extension import** (ADR-252).
- **Tunnel scene**: the acceptance scene found two engine defects, now fixed: a light at the eye
  could print NaN pixels (Schlick base), and surfaces on an interior volume's faces now shade as
  inside.

## For Tincal

Hair cards (ADR-245), compute skinning with eight influences and dual quaternions (ADR-246), eye
gaze and per-instance bind poses (ADR-244), character shading models (ADR-238), rig systems
(ADR-240), spring bones (ADR-237), GPU morph targets (ADR-241), `SkinnedMesh` (ADR-242),
`MorphWeights` (ADR-243), cooked mesh format v2 (ADR-226), and the editor-side features F2 to F14
(ADR-227 to ADR-236, ADR-239). The review fixes of the hair, skinning, gaze, terrain-hole and
lifecycle work are ADR-249.

## Dependencies

`bevy_ecs`, `bevy_reflect`, `bevy_tasks` and `bevy_state` move from `0.20.0-rc.2` to the stable
`0.20.0` (ADR-258).

## Hardening found by the gate

- A glTF mesh whose indices or attribute lengths do not fit is now refused before tangent
  generation (a mutated-file fuzz test found an index panic).
- `check-layers` allows `ferrite_steam -> ferrite_agent` (the optional Steam crate registers
  `steam.status` on the agent extension).

## Known issues

- `warm_coverage` crashes at process exit on NVIDIA after all its tests passed (backtrace
  pending); the gate counts it as a pass and prints `EXIT-CRASH`.
- Timing tests of the emissive fit budget and a few GPU binaries can fail under heavy host load and
  pass alone.
- Review items not yet fixed: see `docs/releases/v0.1.16.md` to `v0.1.18.md` and the follow-up list
  (nearest-layer-only canopy discard before derivative-using calls, cheap sun-shadow coarse bias,
  upload paths outside the out-of-memory scope, the vertex/index buffer cache still keyed by Arc
  address).
- Baked light is not in this release.
