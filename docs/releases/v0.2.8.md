# Regia Engine v0.2.8

Builds on v0.2.7. This release adds these feature sets for game teams:

- **Networking**: client prediction with server reconciliation (spec 73), and lag compensation for hit checks on
  the real input stream (spec 75).
- **Animation**: motion matching completed (exact search on every path, more feature channels, a player with
  inertialization and warps, `.motiondb.ron` files); retargeting on real exporter rigs with a quality report; crowd
  animation with foot locking; montage editing, a graph `Slot` node, reverse playback and time-stretch.
- **Navigation**: off-mesh links v2 (kinds, filters, timed crossings, a link generator, `.navlinks.ron`) and moving,
  turned tile-cache obstacles.
- **Rendering**: runtime lens effects (ghost flare, dirt, chromatic aberration), a lite forward shader for tile GPUs
  on the Mobile presets, a baked-GI brick lookup grid, camera precision far from the origin, and look work on
  cirrus, hashed-alpha canopies, the crash fireball and column, the entry streak and the camera shake.
- **Terrain**: Noise and Ramp sculpt modes, heightmap export and import, a shared wind, and holes and painted weights
  that the editor saves.
- **2D**: auto-tiling rules (`.autotile.ron`) and an editor 2D mode.
- **Content delivery**: `https://` chunk sources, Android store asset packs, the `content.why` reason chain at run
  time, block-checked resume, a free-space check, and an editor Content Chunks tab.
- **Media**: AV1, Opus and Vorbis decoding behind opt-in features.
- **Modding**: optional sandboxed Lua 5.1 mods (`lua` feature).
- **Distribution**: an engine version policy, packaged engine releases (`regia engine`), and
  `regia upgrade-project --engine`.
- **Fixes**: two audit rounds (agent protocol security, gameplay framework, montages, curves, choosers, abilities)
  and render-out fixes from the Red-Rouge smoke.

All new features are off, or unchanged for projects that do not use them, except where **Changed** says otherwise.

The text below consolidates the `v0.1.28-*` release fragments of the lanes merged after v0.2.7 and the integration
notes (ADR-1910, ADR-1947). The fragments: `audit-fix-gameplay`, `b31-net-prediction`, `b33-motion-matching`,
`brick-loop`, `camera-step-quantization`, `canopy-stipple-source`, `cloud-look-override`, `content-delivery`,
`crash-fireball`, `e3-terrain-editing`, `e5-lua-mods`, `e6-retarget-crowds`, `e7-2d-toolkit`, `fix-audit-main`,
`integ-fix029`, `integ-v029`, `lens-effects`, `look-measure`, `look4-canopy-dither`, `look4-cirrus`,
`look4-crash-cap-albedo`, `look4-shake-derivation`, `look4-shake-targets`, `look4-streak-daylight`,
`look5-streak-cap`, `media-codecs`, `mobile-forward-perf`, `montage-m8-m10`, `n2-lag-compensation`,
`p2-navmesh-offmesh`, `p4-distribution-upgrade` and `rr-render-out-fixes`.

## New

### Networking: client prediction and reconciliation (spec 73, ADR-1793)

In `regia_net::predict`:

- One game input type: `regia_net::add_net_input::<I>(world)` / `app.add_net_input::<I>()`, `I: NetInput`
  (`on_missing` decides what the server uses for a missing tick). The game writes `InputCommand<I>` on its controller
  (`NetPlayer`) entity; the server writes the consumed command into the same component.
- Predicted components with a tolerance: `regia_net::predict::<C>(world, Tolerance::...)` / `app.predict::<C>(..)`
  (`Exact`, `Fn`, `Within`; `Tolerance::position`, `angle`, `pose` for `Transform`). Predicted systems:
  `add_predicted_systems` / `app.add_predicted_systems` (schedule `PredictedUpdate`, run from `NetSet::Predict` by
  `net_predict`).
- `PredictionCx` system parameter (`tick`, `is_resimulating`, `first_time`, `is_server`, `simulates`, `owner_player`,
  `spawn_predicted`, `send_local_event`); `NetResimulating` resource while re-running; `NetClock` resource.
- The input stream (unacknowledged commands newest first, `input_redundancy` 16), the server's per-player input buffer
  (one command per tick; missing, late, early and flood counted), the input acknowledgment, and the client lead
  controlled by inserting or skipping a predicted tick (resync on large errors, `net.lead_resync`).
- Prediction history, rollback of every predicted entity to the server state and resimulation, the resim cap,
  correction smoothing (`NetVisualOffset`, `NetVisualChild`), snaps on large errors and teleports.
- `TickDrivenMotion` movers (Once, Loop, PingPong) at the predicted tick; predicted spawns with `NetPredictionKey`,
  bound to the server's spawn, and `NetPredictedSpawnRejected` after the grace period.
- Opt-in client position tolerance (`prediction.trust_client_within_m`) and `prediction.verify_resim` for tests;
  `config/net.ron` section `prediction` (spec 73 § 10).
- Agent methods `net.prediction`, `net.input_buffer`, `net.prediction_history`, `net.force_correction` (guide topic
  `net-prediction`, `book/agents/net-prediction.md`); new `F0002` reason `entity_not_predicted`.
- `LoopbackHub::up_drop`: a test hook that loses chosen client frames.

### Networking: lag compensation (spec 75, ADR-1752)

Plan item D4; build record spec 90.

- `regia_net::lagcomp`, `LagCompPlugin`. Servers record, each fixed step, the world pose of every `HitShapes` shape
  (sphere, capsule, oriented box; on the root or a joint) of replicated entities for `ceil(max_rewind_ms / step) + 2`
  ticks. `LagCompensation::new(&world)` gives `raycast`, `sphere_cast` and `overlap_sphere` at the shooter's view tick
  (clamped to `max_rewind_ms`), `at_tick`, `projectile_tick` / `projectile_view_lag`, and `validate_claim` for client
  `HitClaim` messages (verdicts `view_tick_out_of_range`, `origin_too_far`, `missed_shape`, `occluded`,
  `target_unknown`, counted per shooter).
- Teleports are cuts; despawned targets resolve with `alive: false`; the shooter never hits or is occluded by its own
  entities; shapes on a child follow a moving parent in the same step; ties go to the lower `NetId`.
- Host hooks `LagCompOcclusion` and `LagCompJointSource`; without a joint hook, joints come from the scene hierarchy.
- `regia::lagcomp_bridge` (feature `net`): `LagCompBridgePlugin` installs `physics_occlusion` and `animator_joint`,
  and the gizmo group `net_lagcomp` (off by default).
- Debug echo (`lag_compensation.debug_echo: true`, dev builds): `LagCompEchoPlugin`; clients read it with
  `lagcomp.echoes`.
- The view tick comes from the spec 73 input stream: the consumed command's view tick sets `NetViewTick` on the
  player's controller entity. `crates/regia_net/tests/lagcomp_input_stream.rs` rewinds a shot on the real stream
  (spec 75 test 1).
- Agent methods `lagcomp.stats`, `lagcomp.history`, `lagcomp.raycast`, `lagcomp.last_queries`, `lagcomp.echoes`
  (`book/agents/net-lag-compensation.md`, topic `net-lag-compensation`); reasons `lagcomp_not_installed`,
  `entity_not_lag_compensated`, `tick_out_of_history`.
- `config/net.ron` section `lag_compensation` (`enabled`, `max_rewind_ms`, `projectile_rewind_ticks`,
  `claim_tolerance_m`, `claim_origin_tolerance_m`, `claim_view_tick_slack`, `max_shapes_per_entity`, `debug_echo`).
- Bench: `cargo run --release -p regia_net --example net_lagcomp_bench`.

### Animation: motion matching (spec 52 gaps, ADR-1831)

- **Exact search everywhere.** Every cost comes from one canonical eight-lane distance
  (`regia_animation::motion_matching::lanes`), so scan, k-d tree, top-k and every platform return the same frame with
  a bit-identical cost. `SearchMethod::Auto` (new default) scans small databases and rare tag filters and uses the tree
  otherwise; it never changes an answer. `search_top_k` runs on the tree.
- **Feature channels:** `FeatureSchema::history_times`, `pose_joints`, `sample_weights`, `normalization`
  (`GroupDeviation`, `PerDimension`, `None`). A schema without them keeps the old layout bit for bit. Runtime history
  comes from `MotionMatching::ground`.
- **Cadence controls:** `MatcherSettings::{urgent_threshold, min_search_gap, stagger, play_rate, live_pose_blend}`,
  `MotionMatchBudget`, `SearchReport::{reason, filter_ignored, urgent, method_used, work}`,
  `MatchStep::{jump, deferred}`, `MotionMatcher::{request_search, set_playback_time, candidate_report, current_query,
  record_ground}`.
- **`MotionMatchPlugin`** (opt-in) registers the matcher and player systems and the `JumpEvent` message.
- **`MotionMatchPlayer`**: plays the matched clip, inertializes every jump, strips the root's ground motion and reports
  it as `RootMotionDelta`; optional warps (`PlayerWarps`, `WarpInputs`: stride, orientation, distance matching;
  `motion_matching::warp`).
- **Candidate report** (`MotionDatabase::cost_parts`, `MotionMatcher::candidate_report`,
  `MotionMatching::report_candidates`); **runtime weight overlay** (`MotionDatabase::with_weight_overlay`,
  `MotionMatching::set_weight_overlay`); `MatcherSettings` and `SearchMethod` serialize (serde/RON).
- **Database summary:** `MotionDatabase::{content_hash, mean_scale_hash, median_jump_cost, tag_count, target_count,
  resolve_method, kd_leaf_size}`; `KdTree::{build_with_leaf_size, nearest_k_biased, nearest_biased_counted,
  with_rows}`; build warnings `MotionDatabase::warnings` (`missing_root_motion`).
- **`.motiondb.ron` v1** (`docs/formats/motiondb-ron.md`): `MotionDatabaseSource` and the cooked payload
  (`MotionDatabase::{to_cooked_payload, from_cooked_payload}`; `regia_animation::cooked::{motion_database_type_tag,
  load_cooked_motion_database, MotionDatabaseLoadError}`).
- **Mirrored entries:** `MirrorTable`, `MotionEntry`, `MotionDatabase::build_entries`, `JumpEvent::mirrored`,
  `mirror_pairs` in `.motiondb.ron`.
- Gizmo group `motion_matching` (`regia_render::gizmos::MotionMatchingGizmos`,
  `regia_framework::motion_matching_gizmos`).
- Agent: `anim.motion_match` takes `candidates` and `filter`; `anim.motion_match_set` takes `settings`, `trajectory`,
  `filter`, `weights`, `search: "now"` and `reset`; new `anim.motion_match_database`
  (`book/agents/motion-matching.md`).

### Content delivery (spec 40, ADR-1876)

- `https://` sources (`regia_asset` feature `content-http`, forwarded as `regia/content-http` and
  `regia_dylib/content-http`; off by default): `content.set_source { kind: "http", base_url }`, `HttpSource`,
  `fetch_manifest`, `HttpClient::with_agent`; resume with `Range` requests. Without the feature an `https://` URL is
  refused with `source_not_supported`.
- Android store asset packs: `regia package --platform android --format aab` ships each `fast_follow` / `on_demand`
  chunk as an asset pack; on the device `ContentPlugin` adds the store source (`android_pack`).
  `regia_platform::asset_packs`; `regia_asset::content::StorePackSource`, `PackStore`, `chunk_state_for`.
- `content.why` at run time from `chunk-why.bin` (format `chunk-why` v1): `reason` (`rule`, `follows`, `shared`,

- `[content] base_url` in `Regia.toml`, shipped as `content-host.ron` (format `content-host` v1);
  `REGIA_CONTENT_BASE_URL` overrides it for one run.
- Free-space check before a transfer (missing bytes plus 5 percent; `regia_platform::paths::free_space`), else

## Changed

- **Networking.** `NetPlugin` runs `net_predict` in `NetSet::Predict` (a no-op without an input type or predicted
  component). Clients send an `INPUT` frame per tick while prediction runs; servers send `IACK` frames.
  `NET_PROTOCOL_VERSION` is 2. `net_teleport` also marks the next lag-compensation record as a cut.
- **Motion matching.** `SearchMethod::default()` and `MatcherSettings::default().method` are `Auto` (were `KdTree`;
  same answers, agent reports `"method": "auto"`). `MotionMatcher::reset` keeps the search, jump and deferral
  counters. `step_motion_matching` does nothing once `MotionMatchPlugin` is installed. Costs can differ in the last
  bits (new summation order); baseline jump sequences are unchanged.
- **Retargeting.** `Retargeter::new` and `Retargeter::humanoid` turn opposite-facing rigs by the 90°-snapped yaw
  (`RetargetOptions { align_facing: false, .. }` for the old behavior). Joints the old guesser partly matched may now
  map more roles.
- **Montages.** `ANIMGRAPH_FORMAT_VERSION` is 3 (identity migration; v1 and v2 load unchanged); `regia
  upgrade-project` rewrites the version. A rig whose graph has a `Slot` node advances its montages before the graph.
- **Navigation.** Crowd agents take time on links by default (`Timed`; `NavLinkTraversalMode::Instant` for the old
  teleport). `NavTileCache::revision` also increments when links change. A* prices a walkable step by polygon-center
  distance even where a link joins the same two polygons. `regia_cli` and `xtask` depend on `regia_nav`.
- **Lens effects.** `post-volume` format 1 → 2 (`PostVolume::migrate` maps 0 and 1 to 2; scene files need no
  rewrite; `docs/formats/post-volume-v2.md`). `extract_frame` reads an optional per-camera `LensEffects`. Spec 30 § 8
  no longer lists chromatic aberration, flares and dirt as out of scope.
- **Mobile.** `samples/arena` keeps the post stack on Android, so the Mobile render scale and SGSR apply (desktop
  frames unchanged). New forward axes `FORWARD_LITE_LOW` and `FORWARD_LITE_HIGH` (at most 8 lite compositions per
  device). Spec 13 § 3 gains a row for the tile-GPU forward shader.
- **Baked GI.** `VolumeLayout::runtime_buffer_bytes` includes the brick grid (a few KB); the buffer gains a grid
  section (`VolumeWords::grid`).
- **Camera.** `ExtractedCamera::target` is `look_target(eye, forward)` (a power of two at least four times the eye's
  largest coordinate ahead, one meter near the origin). `CameraPath::heading` differences in `f64`; `LookAt::Heading`
  rotations come from the heading direction. `ShotSample::target` is unchanged (10 m ahead).
- **Hashed alpha.** On a moving view the hashed alpha test uses a lattice-free per-pixel phase; held views keep
  interleaved gradient noise. Frame uniform `interior_half.w` gains flag bit 5 (view held); no layout change.
  `lab_forward.wgsl` changes, so pipeline caches recompile once.
- **LOD and impostor fades** threshold with interleaved gradient noise (golden-ratio step per frame) instead of a 4×4
  Bayer cell (ADR-1474).
- **Cirrus** (ADR-1470) draws fallstreak trails instead of evenly spaced strands; bands read less covered at the same
  optical depth. The sheet is evaluated once per cloud-march texel; `cirrus_ridge` is no longer used by the shader.
- **Clouds.** With a `Weather` driving the clouds, look fields given to `render.set_clouds` are kept as an override.
- **Crash fireball** (ADR-1498): sized by what is seen (at 250 t the flame's equivalent diameter peaks at 195 m full /
  188 m lite in the CPU footprint); 36 (lite 14) layered sheet cards on a shell; a soot toroid with a new `soot_ring`
  emitter; the flash is a smooth additive glow; body light reaches `80 R`; spawns 0.55 R above the crash point (was
  0.35 R). `CrashMeasure::fireball_peak_radius` / `fireball_peak_time` measure the seen flame. The billboard shader's
  fire-light term uses the sphere-source knee for lights reaching 400 m or more.
- **Crash column** (ADR-1472, ADR-1490): cap and stem are grey-white condensation, snow powder and dust; soot burst 40
  (full) / 18 (lite) puffs (was 56 / 24); cap split into `cap`, `cap_veil` and `cap_wisps`; self-shadow 0.72 (was
  0.88); aging cap puffs grow up to 1.3x and thin by the same factor.
- **Entry streak** (ADR-1471, ADR-1490): soft round head, short tapering wake, 3 s afterglow (was 14 s); the dust train
  has about half the opacity, warm grey `DUST_COLOR` and fades 24 s after deposition (was 240 s). Visible colors use
  `glow_color` (3500–6000 K). The trail shader text changed (caches recompile once).
- **Camera shake** (ADR-1473, ADR-1475): seismic phase of the showcase blast under 1 px (`mount_q` 0.8); the airblast
  is one jolt of about 3.5 px (`stiffness_n_m` 57,600, `air_decay_s` 0.4), no oscillation; a near blast is held to the
  2 degree ceiling. `GroundShock::legacy()` and `shake_profile: "legacy"` keep the ADR-1457 values.
- **Terrain.** `GrassParams` gains a `wind` vec4 (224 → 240 bytes); the default wind reproduces the old look.
- **Content.** `regia`'s default plugins add `ContentPlugin` (no-op without a manifest); on Android the manifest, chunk
  map, reason table and host record are extracted from the APK. Pausing or cancelling leaves a `Verifying` chunk
  alone. `regia assets chunks` uses `summarize_chunks` (same JSON); `regia package` stages `chunk-why.bin`.
- **Media.** With a codec feature on, AV1, Opus and Vorbis report `supported`; without it the `codec_unsupported` hint
  names `media-codecs`. The session drains the video decoder at end of stream and takes audio rate and channels from
  the decoder when it knows better.
- **2D.** `regia_editor` depends on `regia_2d`; `editor.save_level` answers with `tilemap_saved`.
- **Distribution.** `regia upgrade-project` reads `Regia.toml [project] engine` and refuses (exit 1) `engine_too_old`,
  `upgrade_unsupported` and `engine_requirement_invalid`; `--write` stamps this engine's line (with `Regia.toml.bak`).
  It no longer scans directories holding an engine. `regia new` and New Project write `engine = "0.2"` (template
  placeholder `{{engine_line}}`) and the engine's `Cargo.lock`.
- **Render-out** (ADR-1881). A job's own state restarts when it starts (`Time::elapsed` and `Time::sim_elapsed` from
  zero, no banked fixed time, weather clocks, mesh LOD, terrain and lens noise); the world is not rewound (see "What
  repeats" in `book/agents/render-out.md`). Outputs close on a worker thread. `render.out_start` `out` and every
  parameter on the same rule use `regia_core::project_path::resolve_in_roots`: relative paths refuse `:` and device
  names on every host, dangling symlinks are refused, an absolute path through a symlink landing under an allowed root
  is accepted. The refusal message also names the symlink rule (ADR-1947).
- **Agent security** (ADR-1769). `demo.inspect`, `demo.seek_plan` and `replay.load` take `path` only under the
  `render.out_start` roots (relative paths join the project root; else `F0002`). `audio.render_check { wav: true }`
  confines `out_dir`; `out_dir` checks (also `seeing.dump_resource`) refuse symlinks out of the roots. Handshake
  timeout 10 s; at most 8 queued notifications per connection. Token and `endpoint.json` are written by
  rename; a new `.regia/agent` directory is mode 0700 on Unix. Audit log lines truncate method (128 bytes) and
  `agent.hello` client/model (256 bytes).
- **Input validation.** `smartobject.search` refuses a non-integer `limit` (`bad_query`); a malformed `user` is
  `bad_query`, a well-formed id of no live entity `entity_not_found` (ADR-1910 (4)). `water.set` refuses a fractional
  `open_sea.count`. `curves.set_curve` refuses a non-string `rename`; `abilities.grant` refuses out-of-range `level` or
  `input_code`; `abilities.activate` a malformed pick; `chooser.set_options` a malformed `recency`;
  `audio.capture_start` `off_threshold_db >= on_threshold_db` (all `bad_value`).
- **Gameplay** (ADR-1809). Curve handles are invalid in another table or after a reload that changes curve names or
  order. `CurveTables::edit` applies edits to a copy. A chooser raises `ChooserPicked` for an unchanged row when the
  table changed and outputs differ. An ability cost that does not take hold is `cannot_afford` (not charged, no
  cooldown). A held state-tree transition fires on the first tick at or after its hold completes.
  `AbilityStats::live_effects` stays current; `VoiceStreamSnapshot::chunks_dropped` also counts queue overflow.
- **Other.** `regia cook` lowercases and trims `--platform`; `GpuFamily::native_on` ignores case. `loc gather` reads
  symlinked files and does not follow symlinked folders. `ValidationReport::from_ron` fails with `report_invalid`.
  Editor curve edits refuse non-finite keys. `cargo xtask fetch-test-assets` records each model's stated license
  (it had labelled them CC0). The physics cloth contracts list error codes sorted; `physics.cloth_set_params` lists
  `cloth_non_finite` (ADR-1947).
- **Integration** (ADR-1910). `regia_dylib` forwards `media-codecs`, `media-codecs-asm`, `content-http` and `lua`. Lane
  `sprint-lightmap-1` merged design docs only (ADR-1100 and `specs/lightmaps.md`); its UV2 generator,
  `check_lightmap_uv` and `editor.lightmap_uv` lost to the shipped ADR-860 generator (ADR-1910 (3)). Workspace version
  0.2.7 → 0.2.8 (61 workspace members incl. the new `regia_script_lua` and `crowd_lab`).

## Known issues

### Networking

- Spec 73 § 9 character integration (`step_character`, `MoveResult::ground_entity`, `NetCharacterPlugin`),
  physics-driven moving bases and predicted root motion are not built (ADR-1793 (2)).
- With spec 72 budgets installed, a deferred delta of a predicted entity costs a correction (ADR-1793 (10)).
- The spec 73 § 14 Pixel 6 budget (8-tick resimulation under 1.0 ms) is not measured.
- `PoseSource::Joints` uses the joint pose of the last animation evaluation (a frame old when animation runs per
  frame).

### Animation and navigation

- Motion matching: no mirror tables in the skeleton asset, no cook step in `regia_asset_pipeline`, no motion-database
  asset registry (`anim.motion_match_database` takes an entity), no editor panels, no `Reflect` on the components. The
  player's pose is not wired into `Animator`; the host applies `MotionMatchPlayer::pose`. Spec 52 § 10 budgets are not
  measured on the min-spec laptop or Android.
- Crowds: mid-blend skate between gaits with different duty factors in shared and interval tiers (foot locking covers
  exact tiers only). Rigify center chains need a `.retarget.ron` with overrides. No CI test runs real clips.
- Montages: the timeline editor panel (spec 34 M10 UI) is not built. Reverse play does not warp root motion or lead
  sync groups (by design). Slot rename finds references by a project text scan.
- Navigation: `nav.generate_links` sees only the mesh (cannot tell a thin wall from a gap; pass `TriangleClearance`
  from game code). Agents move in a straight segment on a link. No link reservation and no area costs.

### Rendering and look

- Lens effects: screen-space flare (off-frame lights cast no ghosts); one built-in lens and iris, no starburst or lens
  picker; runs before depth of field and motion blur; targets and dirt mask are created on first use; no golden
  covers the look and an owner by-eye check against reference plates is pending.
- Mobile lite forward: tile-GPU Mobile frames give up skin, eye, hair, sheen, clearcoat, anisotropy, detail maps,
  wear, parallax, specular AA, multi-scatter, SSAO, contact shadows, probes, baked GI volumes, mesh occluders, ground
  bounce and translucent shadows; 4 (Low) or 8 (High) lights per cluster; Mobile Low sun shadows end at 40 m
  (`forward_lite::LOW_SUN_RANGE_M`) and it has no anti-aliasing. Material graphs still pay for the full forward
  shader; the full pipeline is still built at startup. Not measured on a Mali GPU or the Pixel 6.
- The renderer ignores camera roll on main views (shot roll tracks and shake roll do not reach the image; ADR-1488
  follow-up).
- Hashed coverage still carries fine noise under motion. The LOD cross-fade and impostor dithers (ADR-1474) keep the
  interleaved-gradient-noise lattice during a fade (follow-up).
- Baked-GI brick grid GPU timing measured on lavapipe only.
- Clouds: `genus`, `coverage`, `cloud_type` and `density` set through `render.set_clouds` are still overwritten by a
  driving `Weather` (use `render.set_weather`); without a genus layer, clearing the override leaves the last look.
  The new cirrus was judged on showcase shot 3 only.
- Crash: shot 4 orange peaks at 168 m (5090, 4K Cinematic); the soot toroid is not legible at 3.3 km in the first 5 s;
  sheet flame tongues show on the ball's top silhouette; the crash bench is not re-measured. The column is one color
  for every ground and energy source; the ejecta fountain is still dark soil over snow; close cameras can pick out
  single puffs.
- Entry streak: the dust color is fixed (no backlit darkening or low-sun reddening).
- Lens effects, the crash fireball and the hashed-alpha change wait for the owner's look check. Several look lanes
  (shake, streak dust and crash cap, canopy dither) were not compiled or rendered on a GPU by their lanes.

### Terrain, 2D and content

- Terrain: foliage sway and its shadow class are not built (v0.4.0); wind is uniform; holes are shapes, not a raster
  brush; a level does not name its terrain (the host inserts `TerrainCookTarget` and loads the holes and weights
  files); no scatter brush, and grass density edits are not saved.
- 2D: the editor pane shows animated tiles on their base tile and draws no sprites other than the map;
  `.autotile.ron` is not cooked.
- Content: store packs verified on one phone in the store's local testing mode only; an in-flight transfer across an
  activity pause is not verified; local testing hands back a pack from an earlier install with the same version code
  (uninstall between runs); `regia package` prints false `pak_compressed` warnings for an AAB; a running game does not
  adopt a newer host manifest.

### Media, modding, distribution

- Media: the picture is not drawn on screen yet (the `media-render` lane). A plain x86 build decodes AV1 too slowly for
  1080p on low-power CPUs (42 ms per picture on a Steam Deck, 9 ms with assembly): use `media-codecs-asm`. The min-spec
  laptop cost and an Android foreground-app measurement are open. A decoder bug is a panic (process exit in shipping
  builds, ADR-1869 § 7). No VP9 decoder and no hardware decode.
- Lua: a hostile Lua pattern can be slow, bounded only by the memory cap (ADR-1751 § 4); the C build adds no stack
  protection or `_FORTIFY_SOURCE` (set `CFLAGS`); no script state in saves and no hot reload yet; the Windows build of
  the Lua C sources was not checked in the lane. ADR-1751 is proposed (owner question Q19 open).
- Distribution: no CI job across two real tags, no release archives, no prebuilt binaries, no registry.

### Agent protocol and tests

- A 32 MiB agent message can expand to several hundred MiB once parsed. `render.out` and `out_dir` writes check
  symlinks once (a racing local process is not stopped). Fracture site sampling on thin solids and the XR late-latch
  window are unchanged.
- A second render-out job in one host that moved its world renders from the later state and its hashes differ, by
  contract.
- The `regia_render` test binary's SIGSEGV at process exit is not fixed here.
- No live-vs-baked GI numbers yet; AMD has no PSNR floors.
- The second UV2 generator of `sprint-lightmap-1`, `check_lightmap_uv` and `editor.lightmap_uv` are not merged.
- Skipped audit findings and their reasons are in the lane reports.

## Golden changes

- No golden image was re-blessed. Rendered frames change by the removed camera quantization (sub-pixel).
- Showcase render-out hashes change: moving shots with hashed foliage, shots with mid-fade LOD or impostor bands,
  scenes with cirrus, shot 3 (entry streak), shot 4 from the detonation frame on (crash fireball and column) and shot 4
  frames 337 to 600 and 879 on (camera shake).
