# Regia Engine v0.2.7

Builds on v0.2.6. This release adds these feature sets for game teams:

- **Multiplayer sessions and a dedicated-server host** (`regia_net`): the session lifecycle from handshake to
  `InGame`, level travel, kicks, bans, reconnect grace, a content manifest, streams and a network conditioner; and a
  server host with `server.toml`, tick pacing, level rotation, an operator console, remote admin and `/health`.
- **Procedural content**: splines, shapes, polygons, modules along paths and roads (CPU side); biomes and vegetation
  scatter; tiled, multi-scale and anchored runtime generation; procedural plants exported as glTF with wind data.
- **Characters and saves**: crouch that shrinks the capsule, ceilings that stop jumps, platform momentum,
  swing-twist joints, ragdoll joint limits and settling; a save flow with request messages, quicksave and a pluggable
  store (Steam Remote Storage included); a straight-line character move-to; and a `top_down` project template.
- **Cloth and soft bodies**: skinned cloth, tuning, wind fields, self-collision, tearing, moving colliders, LOD and
  three soft-body models (solver half of spec 55; no asset formats yet).
- **Spatial queries for AI**: data-driven `.spatialquery.ron` templates that rank places or entities, a behavior-tree
  leaf and an in-place preview probe.
- **Conversations and captions**: `.conv.ron` conversations with choices and channels, a caption presenter with
  wrapping and accessibility options, and sound captions on `.cue.ron` v3.
- **Video playback core**: the new `regia_media` crate (WebM demuxer, decoder isolation seam, player state machine,
  playlists) and an audio feed in `regia_audio`. No real codec and no picture yet.
- **Content tooling**: asset validation with findings, rules, a reference graph, size map and audit CSV, save and
  cook gates; localization exchange through gettext PO files and compiled shipping bundles.
- **Dynamic GI tiers**: Low, Medium, High and Ultra sizes for the Depth lighting option's probe field, with a player
  setting and agent methods.
- **Platforms**: Android APK builds work again, the Adreno 643 launch crash has a workaround, heavy frames on Wayland
  no longer fall to a third of the refresh, and the Android and Steam Deck passes are repeatable from scripts.

All new features are off, or unchanged for projects that do not use them, except where **Changed** says otherwise
(character crouch, velocity and limp ragdolls; the Depth GI tier on Deck, Desktop Low and Desktop Ultra; the
windowed showcase clock; `play.hitch_report` timing; Wayland frame callbacks; strict agent parameter types).

The text below consolidates the `v0.1.28-*` release fragments of the lanes merged after v0.2.6 and the integration
notes (ADR-1875). The lanes: `adr-public-specs-source`, `android-pass-v025`, `b17-net-session`,
`b18-procgen-spline`, `b19-procgen-biomes`, `b20-procgen-66-68`, `b22-asset-audit-loc`, `b24-media-video`,
`b26-cloth`, `b28-envquery`, `b32-dialogue`, `deck-pass-v025`, `fix-cleanroom-audit`, `integ-specs-merge`,
`integ-v028`, `p1-character-save-templates`, `p3-character-physics`, `p6-guides-book`, `r1-dynamic-gi`,
`specrev-r7`, `specw-net`, `specw-proc`, `specw-w1`, `specw-w2`, `specw-w3`, `tq-agent`, `tq-asset`, `tq-ecs`,
`tq-nav`, `tq-physics`, `tq-scene` and `windows-pass-v026`.

## New

### Networking: session lifecycle (spec 77, ADR-1663)

In `regia_net::session`:

- `SessionServer` / `SessionClient`: sans-IO state machines on simulated or monotonic time. Client states
  `Disconnected`, `Connecting`, `Handshaking`, `Loading`, `Joining`, `InGame`, `Disconnecting`; server peer states
  `Handshaking`, `Loading`, `Joining`, `InGame`, `Grace`, `Gone`; per-state timeouts and one-second keepalives.
- The handshake: `Hello` with a fixed 16-byte prefix (`b"RGNH"`, protocol version, protocol hash), so a foreign
  version still gets `version_mismatch`. Checks in order: version, protocol hash, content manifest, password and
  `SessionAuthenticator` (with `Pending` polling), bans, reconnect token, capacity (players, reserved slots), then
  `SessionRules::on_player_joining`. `Welcome` carries the peer id, session id, tick, level, travel id, motd and a
  reconnect token.
- `regia_net::session::DisconnectReason` with the 19 stable codes of spec 77 § 7.1 (`client_quit` ... `suspended`).
- Join snapshot (removed level entities, spawn records, `InGame` marker) through a `JoinSnapshot` provider; level
  travel with `travel_id`, per-peer completion, stale `LevelReady` ignored, travel during loading restarts it.
- Kicks of one player or a whole peer, drain (`server_shutting_down`), reconnect grace that keeps the `PeerId` (also
  for `suspended` clients, also on a full server), and bans (`bans.ron` v1: platform id, address and CIDR range, name;
  expiry; atomic save; an unreadable file is never overwritten).
- Content manifest (`net-manifest.ron` v1): gameplay-only hashes per logical pack plus mods, a sorted mismatch detail
  of at most 32 items.
- Streams: up to 64 MiB, four in flight, paced under `stream_share` of the connection budget, with progress, complete
  and failed events.
- Conditioner (`session::conditioner`): seeded per-direction latency, jitter, loss, duplication, reorder by extra
  delay and a bandwidth bucket; presets `off`, `lan`, `good`, `average`, `bad`, `terrible`.
- `SessionHub` / `LoopbackClients`: the whole lifecycle in one process on simulated time, deterministic under a seed;
  simulated clients (`SimInput::Idle`, `Random`, `Recording`; `*.siminput.ron` v1, dev only).
- `NetSession` resource (`host`, `host_on`, `host_local`, `connect`, `connect_on`, `disconnect`, `suspend`, `travel`,
  `kick`, `kick_peer`, `ban`, `send_stream`, `add_simulated_clients`, `remove_simulated_clients`,
  `clear_simulated_clients`, `set_conditioner`); `SessionRules` (`on_player_joining`, `on_player_dropped`,
  `on_player_resumed`, `on_player_left_reason`, `on_travel_finished`, `allow_idle_slowdown`, `match_over`);
  `app.set_session_rules(..)`; `NetSessionPlugin` (session in `PreUpdate` after `NetSet::Receive`; a `NetPlayer`
  entity per remote player from `Welcome` to `Gone`, `NetDropped` during the grace); `NetSessionEvents`.

### Networking: dedicated-server host (spec 76 § 4-§ 9, ADR-1663)

- `regia_net::server_host`: `server.toml` v1 with precedence defaults < file < environment < command line,
  field-level validation (exit 2) and unknown-key warnings; host states `Starting`, `Loading`, `Running`, `Draining`,
  `Stopped`; tick pacing through `HostClock` (`TestClock` for tests) with overrun counting and p99; level rotation at
  match end; idle slowdown when the game allows it; SIGTERM/SIGINT drain (a second one exits at once) and SIGHUP
  reload on Unix.
- The operator console (`status`, `players`, `kick`, `ban`, `unban`, `bans`, `level`, `next`, `say`, `reload`,
  `quit`, `help`); remote admin (`AdminLogin`, `AdminCommand`, `AdminOutput`); the read-only `/health` endpoint; exit
  codes 0, 2, 3, 4, 70. `SessionOnlyGame` and `AppHostGame` plug a game in.
- Format pages `docs/formats/bans-ron.md`, `net-manifest-ron.md`, `server-toml.md`, `siminput-ron.md`; the `session`
  section of `docs/formats/net-ron.md`.

### Procedural content: splines, shapes, polygons, roads (spec 64, ADR-1664)

- **Spline component** `regia_scene::spline::Spline` (`spline` v1): cubic Hermite segments with `Auto` (centripetal
  Catmull-Rom), `Linear`, `Free`, `Aligned` and `Step` tangents, roll, width/height scale and typed per-point values.
  `SplineCurve` evaluates length, samples at a distance, parameter or key (position, rotation-minimizing or world-up
  frame, curvature, interpolated values), closest point, adaptive polylines, bounds and exact sub-curves (`range`,
  `split_at`, `with_points_at`). No libm calls: the same spline gives the same bits everywhere.
- **Shape component** `regia_scene::shape::Shape` (`shape` v1): box, sphere, capsule or convex hull (up to 256
  points) with an edge band; `contains`, `signed_distance`, `aabb`, world-space distance and region value.
- **Polygons** `regia_procgen::polygon`: union, intersection, difference, xor, offset (miter, round, square joins),
  cut by polylines with a gap band, containment, area, centroid and triangulation, on a 1 mm integer grid (identical
  results on every platform).
- **Nodes**: `sample.spline`, `spline.from_points`, `spline.simplify`, `spline.split`, `spline.intersect`,
  `spline.offset`, `spline.reverse`, `spline.clip`, `polygon.from`, `polygon.bool`, `polygon.offset`, `polygon.cut`,
  `polygon.to_spline`, and `spline.modules` with its pattern language (`repeat`, `first`, `pick`, `gap`; `Stretch`,
  `Scale`, `Gap` fits) for fences, walls and rails.
- **Generated meshes and roads (CPU side)**: `spawn.spline_mesh` bends module meshes along splines; the road profile
  format `.road.ron` (`road` v1, `regia_procgen::road::RoadProfile`); `road.ribbon` (crowned carriageway and
  shoulders that never dip under the terrain, edge points for curbs), `road.markings`, `road.exclusion` (a polygon
  per road) and `terrain.flatten_road` (bake-only terrain edit records, gated by `allow_terrain_edits` and
  `ProcGenSettings::terrain_edits`). Their meshes land in `RunOutput::meshes` (not drawn or baked yet).
- **`RoadOf` component** (`road-of` v1) marks a spline entity as a road with a profile.
  `in.entities { as: splines | shapes | all }` reads level `Spline` and `Shape` components; editing a read spline or
  shape marks the generator stale.
- **Terrain height patches** `regia_terrain::edit::apply_height_patch`: writes a rectangle of heights, records the
  GPU dirty rect and re-cook cells, and returns a `HeightPatchUndo` that restores the samples bit for bit.

### Procedural content: biomes and vegetation scatter (spec 65, ADR-1665)

- **`regia_procgen::biome`**: `BiomeDef` (`.biome.ron`, `biome` v1, every field defaulted,
  `docs/formats/biome-ron.md`) with layers (candidate sources `Ground`, `Poisson`, `ScatterClass`, `Graph`), channels
  (`Slope`, `Altitude`, `Mask`, `Attr`, `Random`, `Rest`), weighted entries (mesh, prefab or spacer), feathered
  filters (`Altitude`, `Slope`, `Density`, `WaterDistance`, `Mask`, `Attr`, `Graph`), a two-radius footprint,
  placement, render settings, children and optional grass multipliers. Loading reports every rule violation
  (`biome_invalid`, `biome_entry_unknown`).
- **Areas**: `BiomeArea` component (`biome-area` v1): one biome over the entity's shape, or a biome map texture whose
  8-bit keys select biomes (`ProcBiomeMaps`). Claims fall from 1 to 0 across `blend_m`; overlaps resolve by priority,
  ties by guid; `preview_alone` regenerates one area by itself in the editor. Spline areas, shape areas and spline
  corridors use spec 64's `Spline` and `Shape` (integration).
- **Nodes**: `biome.areas`, `biome.layer`, `biome.resolve`, `biome.exclude`, `biome.spawn`, `biome.grass_mask`,
  `biome.stats` (99 node types in all), and the starter graph `starter/biomes.pgraph.ron`
  (`regia_procgen::biome::STARTER_BIOMES_GRAPH`). An exact Euclidean distance transform gives distance to water;
  level entities tagged `procgen_exclude` remove the points inside them.
- **Grass**: `biome.grass_mask` exports `grass_multiplier/<class>`; `regia_terrain::grass::GrassMultipliers` (also a
  resource) and `MultiplierImage`; `GrassMaskInputs::multipliers` multiplies each class's density before quantization
  (a multiplier of 1 leaves the bake byte-identical).
- **CLI**: `regia procgen import-scatter <file.scatter.ron> --out <dir>` converts a scatter set into a biome.

### Procedural content: tiled and anchored generation (spec 66, ADR-1666)

- **Tiles** (`regia_procgen::tiles`): `ProcGenerator::tiles: Option<TileSettings { cell_m, halo_m, runtime }>`.
  World-aligned cells run over their rectangle plus a halo (default twice the graph's declared reach, at least 4 m)
  and keep only the outputs they own. A graph without neighborhood nodes gives exactly its untiled output; on the
  2 km x 2 km, 400 000-candidate `points.prune` test map, 5 of 208 494 instances differ with an 8 m halo (4 687 with
  none). `stale_cells` marks only the cells whose halo contains an edit.
- **Tiers**: `tiles.tier { cell_m: Base | Whole | Meters(m) }` and `tiles.no_clip` nodes; `TierPlan` checks nesting
  (`tier_not_nested`) and direction (`tier_upward_edge`).
- **Anchored runtime generation**: `ProcGenAnchor` component (`procgen-anchor` v1), `AnchorSettings` (radii per tier
  with hysteresis, view gate, priority by distance and facing, start/running/apply budgets including the
  deterministic `apply_budget_elements`, pool accounting, memory cap, quality scaling). `GeneratorTiles::step` plans
  deterministically; `procgen_schedule` (`ProcGenSet::Schedule`) runs cells on the compute pool and gives each
  resident cell its own output entity (`ProcTileCell`). `ProcGenSettings::paused` freezes scheduling.
- **`.pgout` cell table**: per cell `i, j, tier`, byte range and output hash; `pgout::encode_cells`, `read_table`,
  `decode_cell`, `replace_cell` (re-baking one cell leaves every other cell's bytes unchanged).
- **Declared reach** (`NodeKind::reach_m`) on `points.prune` (new setting `max_footprint_m`, default 8),
  `points.neighbors` and `sample.poisson`; `points.prune` counts `seam_mismatch_risk` in tiled runs.

### Physics: character controller and ragdolls (spec 93, ADR-1693)

- **Swing-twist joints** (`regia_physics::JointKind::SwingTwist`): a ball joint with bend, side and twist ranges in a
  joint frame, centered on a rest rotation.
- **Crouch shrinks the capsule** (`crouch_half_height`), keeps its bottom on the ground and stands up only with
  headroom; the `Transform` stays at the standing capsule's center. `CharacterState::crouched`;
  `CollisionQuery::has_headroom` (defaulted) and `regia_physics::capsule_has_headroom`.
- **Ceilings stop a jump** at once (`MoveResult::ceiling_hit`). **Platform momentum**: a jump or step off a moving
  platform keeps its velocity (`MoveResult::ground_velocity`, `CharacterState::ground_velocity`).
- **Ragdolls**: joint limits from the bind pose (`RagdollBone::limits`, `RagdollLimits`, `RagdollFlex`,
  `RagdollProfile::forward`, `RagdollProfile::humanoid_limited`); settling (`RagdollSettled { rig, face_up,
  root_position }` once per fall; `RagdollBodies::settled`, `face_up`, `frozen`, `simulating`;
  `Ragdoll::settle_speed`, `settle_time`); a budget and switch (`RagdollSettings { joint_limits, max_simulated }`,
  `RagdollSettings::for_tier`); `.ragdoll.ron` v1 (`RagdollProfile::from_ron`, `to_ron`,
  `regia_framework::ragdoll::file`).

### Physics: cloth and soft bodies (spec 55 solver half, ADR-1672)

- **Skinned cloth** (`regia_physics::cloth`): `ClothSolver::set_pose_targets`, `set_pose_maps` (`PoseMaps`: `reach`,
  `standoff`, `pose_pull`, `sim_mix`, `mass_scale`), `set_root_motion`, `set_blend`, `output` (blended positions and
  area-weighted normals), `reset_to_pose`, teleport resets and root inertia; pose targets interpolate per substep.
  `regia_animation::cpu_skin::skin_points` (linear blend, four influences) builds pose targets.
- **`ClothTuning`** (`set_tuning`): gravity scale and override, pose pull compliance, inertia scale, strain caps,

- **Wind**: `WindModel::{Push, Aerodynamic}`, deterministic `Gust`s, `ClothSolver::set_wind` / `set_gust`,
  `ClothSet::set_global_wind`, and the `WindField` component (directional, radial, vortex) sampled each fixed step
  (`gather_cloth_wind`).
- **Self-collision** `SelfCollision::Spheres`; **tearing** (`TearParams`, `drain_torn`, `distance_active`,
  `triangle_visible`); **moving colliders** (`set_collider_previous`); **world snapshots** (`WorldSnapshot`,
  `SnapshotShape`, `SnapshotKind`, `ClothSolver::set_snapshot`; at most 4,096 triangles).
- **States and LOD**: `ClothState` (`Inactive`, `Settling`, `Running`, `Fading`, `Paused`), `set_paused`,
  `set_lod_level`, `cloth::lod::{lod_level, apply_budget}`. Also `ClothSolver::diagnostics` (`ClothDiagnostics`),
  `step_fixed`, `set_config`, `unpin`, `add_triangle`, `centroid`.
- **Soft bodies**: `SoftSolver` with `SoftModel::{Pressure, Tetra, ShapeMatch}`, the `SoftSet` resource and
  `step_soft_set` (installed by `ClothPlugin`).

### AI: spatial queries (spec 33, ADR-1674)

- `regia_ai::spatial_query`, `SpatialQueryPlugin`. A `.spatialquery.ron` asset (`spatialquery` v1) names a generator
  (`NearbyEntities`, `AtAnchor`, `Ring`, `Wedge`, `Annulus`, `Lattice`, `ReachLattice`, `Union`), tests (`Distance`,
  `Facing`, `InsideZone`, `TagMatch`, `Cast`, `Clearance`, `Route`, `RouteAll`, `Snap`), typed parameters and a pick
  (`Best`, `Sample(band)`, `All`). Anchors include the asker, the candidate, tagged or named entities, fixed points,
  blackboard values and Rust `AnchorProvider`s.
- `SpatialQueryManager::run_instant` runs a request at once; `submit` / `poll` run it across fixed ticks under a
  work-unit budget (4,096 units a tick, breadth first). The same world, template, parameters and seed give
  bit-identical items and scores.
- `RunSpatialQuery` behavior-tree leaf (writes the winner to the blackboard); `BtTaskRegistry::register_factory`
  registers configured leaves.
- `SpatialQueryProbe` (reflected component) previews a query in place; the `spatial_query` gizmo group (off by
  default) draws it. The probe system needs the new `regia_ai` feature `spatial-query-probe`.

### Media: video playback, first milestone (spec 50, ADR-1593, ADR-1670)

- **`regia_media` crate** (layer 3): an in-house WebM / Matroska demuxer and `probe` for untrusted files (64 MiB
  allocation cap, resync, encryption refused); the codec rule (royalty-free only: pooled codecs are refused with
  `codec_patented`, MP4, MOV, AVI and TS with `container_unsupported`; AV1, VP9, Opus and Vorbis are refused with
  `codec_unsupported` until their decoders land); reference raw I420 and float PCM codecs; the decoder isolation
  seam (`isolate`); a synchronous `Session` for `Lockstep` and a `WorkerFeed` decode thread; `PlayerCore` (clocks,
  accurate and keyframe seek, frame stepping, seamless loops, chapters, buffering); playlists with a seeded shuffle;
  `.video.ron` and `.videolist.ron` v1; fullscreen fit math; a CPU YUV-to-RGB reference (BT.601, BT.709, BT.2020)
  and FNV-1a frame hashes; a fixture muxer; `MediaPlugin` with `VideoPlayer`, `VideoPlayerState`, `MediaFiles`,
  `MediaSettings`, `VideoMessage`, `VideoRegistry`; the decoder benchmark
  (`cargo run -p regia_media --release --example decode_bench`).
- **`regia_audio::media_feed`**: `PcmFeed::channel` (a lock-free SPSC ring), `AudioClock`, `MediaAudioRegistry`, and
  `MediaStreamData`, a kira sound that plays a feed on a named bus. `Audio::play_media_feed` matches the bus without
  case and falls back to Master; `AudioPlugin` attaches pending feeds (`attach_media_feeds`).

## Fixed

- **Android APK builds failed since v0.2.0** (ADR-1749): the brand rename wrote the theme as `Theme.Regia Engine`,
  which aapt2 rejects, so `regia package --platform android` and `regia install-android` failed in
  `mergeDebugResources`. The theme is `Theme.Regia` again, and a test checks the generated style names.
- **Debug builds panicked on the first rotation after launch** (Pixel 6): `Surface::configure` could give
  `GpuWaitTimeout` while the boot pipeline warm-up submits on a worker. The configure runs in an error scope; that
  race retries next frame, any other error is reproduced unscoped.
- **Adreno 643 (Fairphone 5) crashed at every launch** in the driver's shader compiler on the forward opaque pipeline.
  On a Qualcomm adapter the forward shader is composed with `SUN_SHADOW_PCF_ONLY` (no near tile, PCF cascades, PCSS
  mode draws PCF 3x3), reported as `fallback_sun_shadow_pcf_only`; `REGIA_SUN_SHADOW_PCF_ONLY=1|0` forces it.
  `FORWARD_AXES` declares the define (the closed axis set test of ADR-1552 failed on the merged tree).
- The Android pass merge commit also names a lost-device swapchain leak fix (no fragment gives detail).
- **Heavy frames fell to a third of the refresh on Wayland** (ADR-1750): a window waited for the compositor's frame
  callback before its next frame. A focused window on a vsync mode no longer waits; on the Deck OLED the showcase's
  `Deck` preset went from 30 fps at every cap to 30, 40, 45, 60 and 90 fps at those caps. Unfocused windows keep the
  wait.
- **Deck glyphs**: on a Deck, a pad that reads as Xbox or Generic (the built-in `Steam Virtual Gamepad`) keeps the
  Deck glyphs; recognized pads still switch.
- **Characters**: crouching characters pass under obstacles lower than the standing capsule; a jump under a ceiling
  no longer sticks to it; a jump from a moving platform no longer stops dead in the air.
- **Agent** (ADR-1736): wrong-typed optional parameters are refused (see **Changed**).
- **`regia_asset`** (ADR-1737): `csv::write_record` / `csv::to_string` round-trip a record of one empty field as `""`;
  `pack_importer_version` saturates; `decode_cooked_file` no longer truncates a huge declared payload length on 32-bit
  targets; `CubeLut::sample` / `sample_with` read the first entry for a NaN channel; `LoadSet::bytes` and load-set
  progress saturate near `u64::MAX`; `normalise_asset_path` (and `display_path`) no longer double the root separator
  of an absolute path.
- **`regia_physics`** (ADR-1741): platformer moves with NaN, infinite or huge deltas no longer poison the sub-pixel
  fraction, hang or overflow (deltas are cut to 1,048,576 pixels); `PlatformerWorld::set_actor_size` keeps the bottom

## Known issues

### Networking

- The transport has no encryption yet: `Hello` passwords travel in clear, and remote admin is off except with the
  dev-build override `ServerHost::allow_unencrypted_admin`.
- Windows servers do not catch Ctrl+C, Ctrl+Break or console close yet (`regia_platform::console_ctrl` is not wired);
  use the console `quit` and `reload`.
- The session and the replication bridge (ADR-1643 (15)) use separate connections and keyings; `InGame` does not gate
  replication yet, and the join snapshot is empty unless the game installs a provider.
- Not built yet (ADR-1663 (18)): the `server` build feature and the client-crate split, `regia package --server`,
  `regia server --clients`, the stats overlay, multi-client play-in-editor, `GameRules` join/leave wiring, mods and
  the dev-cache computation in the manifest, join codes in `connect`, owned-entity hand-off on `Gone`, per-player
  ping/loss in `players`, the spec 28 log files.

### Procedural content

- Splines and roads (spec 64) not built yet: drawing, baking and detaching generated meshes, `road.junctions`,
  `road.decals`, applying terrain edit records to the terrain (and restoring them), the `[procgen] terrain_edits`
  manifest reader, `in.self` spline/shape items, editor undo routing for `spline.*` edits, the `procgen_roads` sample
  and the `splines` bench. `spline.reverse` turns `Aligned` points into `Free` ones and does not reverse `Step`
  segments exactly.
- Biomes: `ScatterClass` sources skip classes that use a density map; `TerrainLayer` rules and filters read procedural
  layer weights only. Re-baking the GPU grass when `GrassMultipliers` changes is the host's job. The determinism hash
  is recorded on Linux x86_64 only; `samples/procgen_biomes` and its look-review screenshots are not built.
- Tiles (ADR-1666 (7), (8)): `procgen.bake` writing tiled generators per cell and streaming baked cells with anchors,
  the tile debug overlay, editor "generate around view", the `samples/procgen_open_world` sample, hitch report and
  Pixel 6 run are not built. Anchored generators capture the world once per graph/parameter change, not per cell.
- Plants: `procgen.plant_build`, impostor-atlas billboards, mesh envelopes and the editor preview strip are not built;
  Windows byte equality of plant `.glb` files is not checked.

### Physics

- Character physics cost (the build server, release, loaded host): 16 limp humanoids falling cost 0.72 ms mean / 1.25 ms peak
  per physics step with joint limits (0.47 / 0.87 without), resting 0.10 ms. The peak is above the spec's 1.0 ms
  desktop budget on that host; idle desktop and mobile runs are pending.
- The swing limit is the bounding box of the bend and side ranges. The humanoid limit table assumes a bind pose near
  T-pose or A-pose. A frozen ragdoll ignores hits until its mode changes. A settled ragdoll may rock at up to about
  1 rad/s on some limbs for a second (ADR-1693).
- Cloth (ADR-1672) not built yet: `.cloth.ron` / `.soft.ron` and cooked formats, the cooker and tet generator,
  `ClothSim` and the framework glue (pose sync, body proxies, render section), world snapshots built from the rigid
  world, two-way reaction, vertex-map edits and `physics.cloth_edit_map`, sim-mesh LODs, `VertexTriangle` (runs as
  `Spheres`), garment layers, plasticity, parallel stepping. The spec 55 § 10 budgets are not measured.

### AI, gameplay, dialogue

- Spatial queries: the spec 33 § 6 time budgets are not measured (tests count work units). `server_only` is stored
  but the cook ignores it until an authority-role build profile exists (ADR-1585). No dedicated query editor.
- `MoveTo` walks a straight line (use `regia_nav` for paths). A load respawns `Saveable` entities from reflected
  components only, so a simulated player keeps its state in a saveable resource (`PlayerCheckpoint`); stable entity
  remapping is Tier 2.
- The generated `top_down` and `third_person` projects were compile-checked once by the lane; the `templates` CI job
  is still absent. Generated projects carry no `rust-toolchain.toml`, so a rustup default older than 1.99.0 fails.
- Captions: without a `TextSystem` (headless) layout uses a width model. No `.convc` cook output; packaged builds do
  not load conversations yet. Captions start on the caption clock, not the audio device's sample counter;
  `captions.set_options` `persist` is ignored; the CJK reading speed of 9 per second is a placeholder.

### Media

- No real video plays yet: AV1 (milestone 2) and Opus or Vorbis (milestone 3) decoders are not built, so `.webm`
  files with those codecs are refused with `video_codec_unsupported`.
- The picture is not drawn yet (GPU convert pass, `UiVideo`, the material `video` parameter, fullscreen drawing and
  `[boot] movies` come with the renderer milestone); `video.frame_hash` hashes the CPU reference.
- Video audio is not spatial (`VideoPlayer::spatial` is ignored); lockstep render-out does not take audio in exact
  per-step counts; `video.create_player` is not undoable.

### Content tooling

- Deferred: the spec 32 § 8 editor panels; the spec's `Fail` default for `regia package` (`Warn` until the owner
  decides); spec 36 L2 pak loading of bundles, L4, L5, D1, D2, S1, S2 and `localization.set_key_display`.

### Rendering

- **Light leaks into small closed rooms under Depth** (not new in this release): a sealed 6 x 3 x 6 m room reads
  7.25 % of the sunlit ground inside at the 2 m x 4-cascade layout every tier and Desktop High use (target 0.5 %).
  The two sealed-room acceptance tests are ignored with the reason (`specs/79` § 9.1).
- Dynamic GI cost per tier on the RX 7900, RTX 5080 and the Deck is not measured (lavapipe only); the Deck's default
  lighting option stays Balanced. The screen-space radiance cache is not in this release.

### Platforms

- Android: the forward pass costs about 641 ms a frame on the Pixel 6 and 950-1850 ms on the Fairphone 5 at Mobile
  Low and Mobile High alike; the lighter mobile forward shader (`lane/mobile-forward`) is not merged.
  `samples/arena` turns post off, so it ignores `render_scale` on phones. The Pixel 6 rebooted once by hardware
  watchdog after `am force-stop` (unconfirmed). Debug APKs run with wgpu validation on.
- Steam Deck (Desktop Mode, ADR-1750 (6)): a focused window under a blanked panel keeps rendering on Wayland at about
  30 fps; the Wayland fix ran on KWin with RADV only; the `Deck` profile's 40 fps cap does not divide the desktop
  refresh; telemetry's `bound` and `frame_bound.class` disagree on a capped frame; first launch takes 15 s to the
  first frame with an empty pipeline cache (1.8 s warm); one bind group is created every frame after warm-up
  (showcase); `vfx_lab` `deck_check.json` mislabels `gpu_power_w` and `gpu_mhz`; the sample HUD's soldier cards clip
  under the 12 px Deck text floor. Built-in buttons, Game Mode, sleep and resume and battery-only runs are untested.
- Windows, RTX 5080: three `regia_render --test nan_guards` cases and `atmosphere_golden` sky_noon (SSIM 0.9780)
  fail; `session_harness` and `gltf_extensions` are timing flaky.
- This integration ran on lavapipe only; real-GPU, macOS, device and headset runs are the lanes' open items.

### Specs and docs

- Spec text and shipped code disagree on names renamed in the specs only: spec 32 says footprint map (code:
  `editor.asset_size_map`, `regia assets size-map`), specs 70/76 say `ProcessKind` (code: `regia_net::NetMode`),
  and "Sequencer" stays in `regia_framework::sequencer` (ADR-1661 (5) recommends a rename lane).
- No spec records the public page URLs ADR-1526 (4) asks for. `docs/master-plan.md`, `docs/provenance.md` and
  `docs/versions.md` still say "DCC live link".
- The written specs are unreviewed against the public set for close paraphrase (spec-writer lanes). Specs 50, 53, 55,
  56, 57 and 58 exceed the 450-line target. Owner sign-offs open: spec 61 content and licence text, spec 58 headset.
- Book coverage does not check `tool.<id>.<name>` methods of external editor tools, nested subcommands or stale § 4
  rows.
- `cargo llvm-cov` is not installed on the build server; the test-quality audits were manual.
