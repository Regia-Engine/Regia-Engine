# Ferrite v0.1.7

Patch release for Direct Order 27's alpha (Saturday 2026-10-17): local lights work everywhere on screen, and the audio no
longer drops out during hitches on real GPUs.

- **Commit:** v0.1.7 = the tag `v0.1.7` (the gated code commit is named in the tag message).
- **Workspace version:** `0.1.7`.

## Upgrade from v0.1.6
No host source changes (checked from the code diff: no field added to a public struct). Two behavior changes need a look:
- **Point and spot lights now light what they reach.** Before, almost all of them added nothing (see below). Expect
  muzzle flashes, explosions, hull lamps and base lights to start lighting nearby surfaces: check every light's
  intensity by eye after updating.
- **The slow-frame audio pause is off on real GPUs** (`AudioThrottle::Auto`). Hosts that worked around the v0.1.6
  drop-outs can remove the workaround.

## Fixed
### Local lights only lit what one corner of the screen reached (ADR-186)
The forward shader read the fragment's pixel position as if it were NDC, so every fragment used the light list of the
bottom-right froxel column. A lamp around the camera (a cockpit) covers every froxel and worked; a lamp under a hull 16 m
away covered none of that corner and added exactly 0. Now the lookup uses the pixel position over the screen size, the
layout the cluster builder writes. DO27's black Remora on Bore Twelve: shadow side 48 → 201 cd/m² with a 2.5 M lm lamp
under the belly (it did not change at all before). New test: a small light away from the screen corner lights its
surface (failed before).

### DDGI probes ignored the planet-shine fill (ADR-186)
Probe ray hits took only the sun; they now also take the sky-body fill (Jupiter-shine on Europa maps): shadow sides +2 to
7 %. The fill is not shadowed inside the probe trace (interiors and tunnels can pick up a little of it); GI probes stay
opt-in.

### Audio dropped out during hitches on real GPUs (ADR-187)
The output gate paused the audio after 5 frames slower than 50 ms. That safeguard was meant for software rendering
(lavapipe soaks), but ordinary hitches on real GPUs triggered it: 14 drop-outs in a 13-minute match on an RX 7900 XTX,
11 on an RTX 4080. New `AudioThrottle { Auto, On, Off }` resource: `Auto` (default) arms the slow-frame pause only on a
software adapter (`ferrite_platform::SoftwareRenderer`, published by the renderer), `On` is v0.1.6, `Off` never. The
hidden-window pause is unchanged. Every pause now logs its reason; `Audio::throttle_suspend_count()` counts slow-frame
pauses.

## Tools
- `cargo run -p lookdev --bin hull_terms`: per-term lighting (sun, fill, lamps, emissive, indirect) averaged over a hull's
  pixels, for look diagnosis.

## Known issues
- **Terrain is not lit by point or spot lights** (no cluster path in the terrain shader): flashes and explosions light
  vehicles and props but not the ground. First item after the alpha.
- No local exposure: very dark shadow sides on airless maps (content advice: DO27's Remora albedo ~0.04 and baked AO 0.53).
- Still under investigation (field logs, RTX 4080 on Windows): CPU-bound frames from mesh/material cache churn at
  DO27's scale (render_into ~45 ms on Switchbacks) and the texture budget not scaling with VRAM. Fix in progress.
- Everything listed under v0.1.6 still applies.

## v0.1.7.1 (2026-10-13)
v0.1.7 plus one fix: the project templates' `Cargo.toml` files (which hold `{{placeholders}}`) are now
`templates/**/Cargo.toml.tmpl`, and the workspace excludes `templates/`. A host that depends on Ferrite by git parses the
checkout cleanly again (v0.1.7 broke every fresh build of such a host). `ferrite new` and the editor scaffold are unchanged
for users. The release gate now also resolves each tag as a git dependency from a throwaway host crate.
