# Regia Engine feature inventory

Audit of the v0.7.0 candidate `425b388676` for the v0.7.1 manual.
One row per feature is in `docs/manual/feature-inventory.csv` (same directory).
This page is the reading copy: counts, gaps, and the user-facing tables.

Status values:

- **built** — the feature is in this tree (a public module, a command, a format, a panel, a method, or a spec whose crates exist). Acceptance tests were not re-run.
- **partial** — the code or `docs/versions.md` names a remaining gap (loader missing, SDK not bundled, mock-only proof, testing-only platform).
- **deferred** — `docs/versions.md` parks it or places it after v0.7 (consoles, a general web game target, digital humans, visual-graph code generation, Google Play services, a WASM mod SDK, iOS as a product, fracture level 3).

A **Documented** cell is a path under `book/`, or **NONE**. Several pages separated by semicolons means more than one page mentions the feature. `reference/*.md` is generated by `cargo xtask manual`; this audit did not regenerate it.
